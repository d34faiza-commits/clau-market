## 4. Red Flag (no-go atau syarat khusus)

Bila salah satu muncul, jelaskan aturan CLAU dengan sopan. Kalau klien tetap meminta, **tidak lanjut**.

| Permintaan klien | Jawaban CLAU | Dasar |
|---|---|---|
| "Bikinkan review/testimoni bintang 5" | Tidak bisa; kami bantu membalas review asli dan mengajak tamu asli memberi review | AI-CONSTITUTION § 13, rule 01 |
| "Tulis halal / bintang 4 / CHSE" tanpa sertifikat | Klaim ditahan sampai ada dokumen | Rule 02 |
| "Pakai foto tamu ini" tanpa consent | Wajah disamarkan atau foto lain | Rule 04, UU PDP |
| "Pakai foto AI kamar seolah asli" | Visual AI hanya moodboard berlabel | Rule 07 |
| "Ini password IG-nya" | Kami tidak menerima password; pakai akses partner | Automation level 1 § 5 |
| "Langsung posting saja, tidak usah tunggu approval" | Setiap konten butuh approval tertulis | Rule 08 |
| "Jamin naik 10 ribu followers / full booked" | Kami tidak menjamin angka; kami menjamin deliverable & kepatuhan | Katalog § 5 |
| Usaha di luar hospitality & tourism | Belum dilayani | AI-CONSTITUTION § 2 |
| Paket wedding untuk WNA, open trip tanpa izin operator, promosi alkohol ke audiens muda | Butuh review legal dulu | [regulasi](../knowledge/regulasi/hospitality-content-2026.md), TASK-053 |

## 5. Audit Singkat Akun (gratis, ±30 menit, sebelum proposal)

Ambil **3 post terakhir** dari akun publik klien. Catat temuan untuk proposal, tanpa menyalin data tamu.

| Cek | Temuan |
|---|---|
| Klaim tanpa bukti (view, jarak, "terbaik", halal) | |
| Harga tanpa periode/syarat (net/++, minimum malam) | |
| Wajah tamu/anak tanpa indikasi consent | |
| Visual AI/edit berat tanpa label | |
| Konsistensi voice & bahasa | |
| Review yang belum dibalas (jumlah, umur) | |
